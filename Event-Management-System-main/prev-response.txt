| API documentation | OpenAPI/Swagger |
| Database migrations | Prisma migrations |

For a new frontend, I would use Next.js App Router. The Pages Router is still supported, but Next.js recommends App Router for newer capabilities. [Next.js App Router documentation](https://nextjs.org/docs/app)

I would prefer PostgreSQL because registrations, payments, capacity, and check-ins require relational constraints and transactions. Prisma documents transaction support for PostgreSQL, while MongoDB requires lower-level driver sessions for multi-document transactions. [Prisma transaction documentation](https://www.prisma.io/docs/orm/fundamentals/transactions)
